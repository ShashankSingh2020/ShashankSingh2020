### ⚡ [VoltFleet](https://github.com/ShashankSingh2020/VoltFleet) — EV Fleet Intelligence & Smart Charging Platform

A multi-tenant platform for electric-vehicle fleets: telemetry ingestion, anomaly detection, cost-aware charging schedules, a live map and an AI assistant.

- 🏢 Multi-tenant architecture with JWT auth, four roles and **tenant-isolation tests**
- 📡 Idempotent, validated telemetry ingestion with **tenant-scoped WebSocket streaming**
- 🔋 Deterministic **smart-charging optimizer** that respects deadlines and time-of-use tariffs
- 🚨 Rule-based anomaly detection on a **Celery Beat** schedule
- 🤖 Context-grounded AI assistant (Gemini with mock fallback) and a React dashboard
- 🧪 `Python` `Django` `DRF` `PostgreSQL` `Redis` `Celery` `Channels` `React` `Docker`
