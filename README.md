## 👋 About Me

Hi, I'm **Shashank Pratap Singh**, a B.Tech student in Electronics & Communication Engineering at Bangalore Institute of Technology, with a strong interest in software development.

My primary focus is **Python backend engineering**. I enjoy building applications that go beyond basic CRUD operations — systems with authentication, role-based access control, multi-tenant data isolation, asynchronous processing, audit trails, and reliable database workflows.

I also integrate AI where it adds practical value, including repository analysis, document retrieval, and customer-support automation.

On the frontend, I have **basic working knowledge of React, HTML, and CSS**, which I use alongside backend technologies to build interfaces and dashboards for my projects.

- 🔭 Building backend-focused projects with real-world engineering concepts.

### 1. ⚡ VoltFleet — EV Fleet Intelligence & Smart Charging

**[View Repository →](https://github.com/ShashankSingh2020/VoltFleet)**

A fleet-management platform focused on electric-vehicle telemetry, charging optimization, operational monitoring, and real-time updates.

**Highlights**
- Telemetry ingestion with validation and duplicate handling.
- Multi-tenant organization boundaries and role-based access.
- Smart-charging scheduling using vehicle deadlines and electricity tariffs.
- Anomaly detection for battery temperature, sudden charge drops, and stale telemetry.
- Real-time communication using Django Channels and Redis.
- React dashboard integrated with the backend API.

**Tech:** Python · Django · DRF · PostgreSQL · Redis · Celery · Django Channels · React · Docker
